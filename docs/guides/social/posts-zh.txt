整理了一版直播同传字幕工具，准备作为基础版本发布。

功能：本机识别声音，自选 OpenAI 兼容翻译服务；阅读语言可多选，审核/发送只用一种语言；支持悬浮字幕、OBS 字幕页，以及已审核 SRT/CSV 导出。

哔哩哔哩 / YouTube / 猫耳FM 一次只连接一个平台。默认人工审核后发送，发送需要登录；麦克风与电脑声音无需为识别登录。

当前是 Windows Python 项目，需要先安装依赖和本机模型，不是免安装 EXE。翻译 API 可能收费或限流，结果请人工核对。

记录默认关闭；字幕、密钥和 Cookie 请勿公开。图为独立演示数据。中/日/英指南已准备，公开项目名称与链接待补充。
