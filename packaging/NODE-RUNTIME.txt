Node.js portable JavaScript runtime for yt-dlp

yt-dlp's default EJS dependency is included. Its YouTube signature solver
requires a JavaScript runtime. The portable PyInstaller runtime hook supplies
the bundled Node executable when YoutubeDL has no explicitly configured
JavaScript runtimes. Explicit caller configuration remains respected.
No npm install, Node system installation, or Deno installation is required.

The exact official archive's LICENSE contains the Node MIT license and full
third-party license/copyright notices, including V8, OpenSSL, libuv, ICU,
and the other compiled dependencies. That file is included verbatim.
Only node.exe is bundled; npm, headers, documentation and developer tooling
from the vendor archive are excluded.

Build preparation:
Download and verify the archive under build/vendor-downloads.
Extract only node.exe, LICENSE and README.md into build/node-vendor.
Run scripts/build_portable.py after installing requirements-build.txt.
